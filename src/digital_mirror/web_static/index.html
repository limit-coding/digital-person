Ⅰ

固定截止时间

先封住结局，再让系统面对当时真实存在的选项。后来的材料只能用于评测，不能偷偷进入输入。

Ⅱ

拆开材料身份

公开表态、私人书信、实际行动、他人回忆和研究者解释分别标注，不把它们混成一段人格描述。

Ⅲ

展示概率而非独白

输出多种竞争假设、证据和反证。流畅的第一人称独白可以用于展示，但永远不冒充真实内心。
